# 235062_PhamThachThao

## Đề tài
Xây dựng hệ thống quản lý sách trên nền tảng đám mây.

- Frontend: React

- Database: MongoDB Atlas
- Quản lý mã nguồn: Git, GitHub
- Đóng gói: Docker, Docker Hub
- Triển khai: Render

## Cấu trúc dự án
- backend/: Mã nguồn API
- frontend/: Mã nguồn giao diện

## Chức năng
- Xem danh sách sách
- Xem chi tiết sách
- Thêm, sửa, xóa sách
- Tìm kiếm sách

Sử dụng file .env để cấu hình môi trường.
Không công khai mật khẩu hoặc chuỗi kết nối chứa thông tin xác thực.
